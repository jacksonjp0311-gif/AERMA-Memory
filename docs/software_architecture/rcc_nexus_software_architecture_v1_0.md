## Nexus Context Integrity

NCI measures geometric navigation integrity.

Components:

- completeness
- link correctness
- pattern rigidity
- invariant compliance
- evidence / validation linkage
- drift freshness
- coordinate completeness

Default weighted form:

    NCI = 0.15 completeness
        + 0.15 link correctness
        + 0.10 pattern rigidity
        + 0.20 invariant compliance
        + 0.15 evidence validation linkage
        + 0.10 drift freshness
        + 0.15 coordinate completeness

Boundary:

    NCI is not code quality proof.

## Agent Self-Location Protocol

Before patching, an agent must:

1. Identify task type.
2. Select context budget.
3. Read Human / RCC Nexus / AI layers.
4. Locate affected modules by shell, meridian, and sector.
5. Read Echo Location records.
6. Inspect source/tests/evidence.
7. Patch the smallest safe surface.
8. Run validation.
9. Update RCC/Nexus if geometry changed.
10. Downgrade unsupported claims.
