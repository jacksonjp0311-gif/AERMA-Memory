# visuals/rcc_nexus

<!-- RCC-MINI-README:START -->

## Purpose

Charts for RCC-N health, NCI components, coverage, and trends.

## S - Formal specification

Charts are generated from `reports/rcc_nexus/latest_rcc_nexus_benchmark.json` and `reports/rcc_nexus/rcc_nexus_metrics_history.jsonl`.

## H - Hooks and integration edges

- Generated by `scripts/rcc/generate_rcc_nexus_charts.py`.
- Referenced by root README.

## A - Artifacts

- `nci_components.svg`
- `rcc_nexus_coverage_chart.svg`
- `rcc_nexus_health_trend.svg`
- `rcc_nexus_surface_map.svg`

## T - Theory or method basis

RCC-N measures navigation context integrity. Charts visualize diagnostic surfaces only.

## I - Invariants

- Charts are not proof of correctness.
- Charts must be derived from current reports.

## E - Example

Run:

    python scripts/rcc/generate_rcc_nexus_charts.py
